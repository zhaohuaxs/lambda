# lambda
基于 Bern 的 Windows / Android 双端压缩包管理器：后续可扩扩展更多端。支持压缩 / 解压 / 密码加密 / 后台任务 / 流式文本与图片预览。A cross-platform (Windows/Android) archive manager based on Bern: extensible to more platforms in the future. Supports compression, decompression, password encryption, background tasks, and streaming previews of text and images.
